# Nepali Tales — Admin Panel

Fast, responsive dashboard built with **Next.js 16**, **Tailwind CSS**, and **shadcn**, powered by **Bun**.

## Getting Started

1. **Install dependencies**:
   ```bash
   bun install
   ```

2. **Run dev server**:
   ```bash
   bun dev
   ```

3. **Build for production**:
   ```bash
   bun run build
   ```

Open [http://localhost:3000](http://localhost:3000) to view the admin panel.
